## Before you begin

- Create a [Paystack business account](https://dashboard.paystack.com/v2/).
- Log in and navigate to “settings” > “API&Webhooks” to generate your test secret key.

<Steps>
  <Step title="Initiate a payment">

    Send a request to the Initialize Transaction endpoint. Replace `YOUR_TEST_SECRET_KEY` with your key.

    ```bash
    curl https://api.paystack.co/transaction/initialize \
      -H "Authorization: Bearer YOUR_TEST_SECRET_KEY" \
      -H "Content-Type: application/json" \
      -X POST \
      -d '{
        "amount": 12000,
        "email": "customer@example.com",
        "reference": "ref-725b78ac-50a7-43ec-bbd3-c2ac519b0180"
      }'
    ```

    `amount` is in the smallest currency unit. 12000 kobo is ₦120.

    **Response**:

    ```json
    {
      "status": true,
      "message": "Authorization URL created",
      "data": {
        "authorization_url": "https://checkout.paystack.com/ork5ztjq3p3vfx1",
        "access_code": "ork5ztjq3p3vfx1",
        "reference": "ref-725b78ac-50a7-43ec-bbd3-c2ac519b0180"
      }
    }
    ```

  </Step>

  <Step title="Complete the payment">

    Copy the `authorization_url` from the response, paste it into a browser to see the Paystack checkout page, and complete the payment.
    ![Paystack checkout page](/images/paystack-checkout-page.png)
  </Step>

  <Step title="Verify the payment">

    Use the `reference` from the first step to check the transaction status.

    ```bash
    curl https://api.paystack.co/transaction/verify/ref-725b78ac-50a7-43ec-bbd3-c2ac519b0180 \
      -H "Authorization: Bearer YOUR_TEST_SECRET_KEY"
    ```

    **Response (trimmed)**:

    ```json
    {
      "status": true,
      "message": "Verification successful",
      "data": {
        "status": "success",
        "reference": "ref-725b78ac-50a7-43ec-bbd3-c2ac519b0180",
        "amount": 12000,
        "gateway_response": "Successful",
        "paid_at": "2026-10-24T03:33:59.000Z",
        "channel": "card",
        "currency": "NGN",
        "customer": {
          "email": "customer@example.com"
        }
      }
    }
    ```

    `data.status` is the transaction status. `success` means the payment is complete.

  </Step>
</Steps>

To receive payment notifications automatically, see [How to Verify Payments With Webhooks](/guides/verify-payments-with-webhooks).
